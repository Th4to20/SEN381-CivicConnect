# CivicConnect - SEN381 Engineering Baseline

## Project Overview
CivicConnect is a platform engineered to manage facility service requests, replacing fragmented communication channels with a single, traceable record.

## Milestone 1 Evidence
This repository contains the controlled artefacts for the M1 Engineering Foundation & Requirements Baseline.  
Problem & Scope: Bounded requirements targeting duplication, lost visibility, and weak accountability.
Traceability: Source-to-acceptance criteria mapping via the Requirements Traceability Matrix (RTM).  
Risk Management: Project-specific risk mitigation and forward engineering considerations.  

## Engineering Governance Controls
In accordance with the SEN381 Master Project Brief, this repository enforces strict team controls:  
The main branch is fully protected.  
Direct commits to main are blocked.  
All substantive artefact changes require a Pull Request and formal peer review before merging.
